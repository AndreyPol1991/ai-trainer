# Как работают AI-агенты — интерактивный тренажёр

Один HTML-файл, работает офлайн. 22 шага + сценарий для лектора («Ход занятия», ориентировочно 11 часов): харнесс, инструменты, схемы рассуждения агента, гардрейлы, инъекции, MCP, память, RAG, evals, экзамен на атаки, наблюдаемость — всё на живых интерактивах.

Шаги, добавленные осенью 2026:

- **6 · Как агент планирует** — «шаг за шагом» (ReAct), «сначала план», параллельный план и самопроверка на одной задаче в четырёх ситуациях: ходы модели, токены, секунды, где какая схема ломается; задание найти самую дешёвую верную настройку.
- **12 · RAG: база и права** — база знаний как конвейер данных (новые, изменённые, удалённые документы, метаданные, снимок с проверкой и откатом), рычаги качества поиска, диагностика «плохо нашли или плохо ответили», матрица доступа и фильтр по правам до поиска, отравление базы.
- **15 · Экзамен на атаки** — OWASP Top 10 для LLM-приложений (2025) и для агентных приложений (2026) как чек-лист требований, набор атак как регресс, правило трёх, ворота выпуска, задание «угроза → мера».
